Project Omiλia
Инновационный тренажёр

Изучайте русский жестовый язык с помощью искусственного интеллекта

Omiλia анализирует движения и форму ваших рук в реальном времени через веб-камеру, помогая легко осваивать жесты РЖЯ без репетитора и специального оборудования.

👁️

Компьютерное зрение

Алгоритмы распознают 21 ключевую точку каждой руки, фаланги и углы пальцев без задержек прямо в вашем браузере.

🎥

Двухэтапное обучение

Сначала посмотрите наглядное видео и прочитайте технику выполнения жеста, а затем закрепите его на практике перед камерой.

🎯

Блиц-опрос и прогресс

Проверяйте изученные жесты в динамичном опросе. Все выученные жесты фиксируются в вашем профиле с детальной статистикой.

Свяжитесь с нами

Мы постоянно развиваем платформу и расширяем библиотеку жестов РЖЯ. Если у вас есть предложения по улучшению, идеи для сотрудничества или вы хотите добавить новый жест — напишите нам!
